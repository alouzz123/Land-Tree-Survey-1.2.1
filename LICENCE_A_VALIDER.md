# Licence à valider avant publication

Aucune licence définitive n’est attribuée dans ce pack.

Avant de rendre le dépôt public et de publier la release Zenodo, le choix de la
licence doit être validé avec le Centre de Suivi Écologique, le projet GALILEO
et les autres institutions concernées.

Après validation, remplacez ce fichier par un fichier nommé `LICENSE` contenant
le texte officiel complet de la licence retenue, par exemple :

- Apache License 2.0 ;
- MIT License ;
- GNU General Public License v3.0 ;
- ou une licence institutionnelle spécifique.

Ne déclarez pas `Apache-2.0` dans `.zenodo.json` avant cette validation.
